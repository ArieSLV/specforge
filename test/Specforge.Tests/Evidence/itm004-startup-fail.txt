NOTE (bug found + fixed during this evidence run): MSBuild's %(RecursiveDir) emits a backslash on
Windows, so production logical names are "specforge.skills/<dir>\SKILL.md". EmbeddedSkillCatalog now
normalizes '\' -> '/' before structural parsing (keeping the original name for stream access).
Guarded by EmbeddedSkillCatalogTests.BackslashLogicalName_IsNormalized.
