  - DecisionServiceTests.Create_WritesFileArtifactAndHistory

Binary integration: list_decisions / get_decision are demonstrated against the live repo in
itm007-dogfood-parse.txt. The write tools (create/set/delete) require the standard MCP request/response
discipline — a client awaits each tool result before issuing the next call (DEC-003: single-session,
no cross-request concurrency). A test harness that pipelines several tools/call frames without awaiting
responses can let a read race ahead of a prior write; real MCP hosts serialize, matching the unit-test
ordering above.
